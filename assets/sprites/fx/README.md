# 戰鬥 VFX 精靈（墨點江湖）

自製硬邊點陣，僅盤內色、透明底、每幀 **32×32**。禁止柔邊光暈／半透明灰。

## 檔案

| 檔案 | 尺寸 | 幀數 | 建議 fps | 綁定 |
|------|------|------|----------|------|
| `slash.png` | 192×32 | 6 | 12–14 | 跟英雄 `attack` **擊中幀**（通常 attack 第 2–3 幀）疊加於武器前方 |
| `spark.png` | 160×32 | 5 | 14–16 | 跟 `hurt`／受擊瞬間，中心對齊命中點 |
| `parry_flash.png` | 128×32 | 4 | 12–14 | 跟 `parry` 成功幀，中心對齊武器／身體中線 |
| `hit_ring.png` | 96×32 | 3 | 10–12 | 可選；受擊圈，跟 hurt 同幀或延後 1 tick |
| `clash.png` | 192×32 | 6 | 12–16 | **雙方攻擊交疊**／`parry` 成功瞬間；中心對齊兩刃接觸點 |

## 對幀（0-index）

### slash.png — 刀光／劍弧
| 幀 | 內容 |
|----|------|
| 0 | 起弧（短金／青綠） |
| 1 | 拉長 |
| 2 | **最亮**（cream 芯 + 金箔／劍鋒 + 硃紅尖） |
| 3 | 滿弧維持 |
| 4 | 斷弧消散 |
| 5 | 碎點收束 |

播放建議：單次 one-shot，唔 loop；可喺幀 2 觸發 SFX 刀斬。

### spark.png — 打擊火花
| 幀 | 內容 |
|----|------|
| 0 | 撞擊亮核 |
| 1 | 十字／放射硬點 |
| 2 | 四散像素 |
| 3 | 外散淡出 |
| 4 | 殘點 |

### parry_flash.png — 招架閃
| 幀 | 內容 |
|----|------|
| 0 | 大十字 + 短放射（cream／金箔，硃紅尖） |
| 1 | 縮一檔 |
| 2 | 再縮 |
| 3 | 滅 |

### hit_ring.png — 受擊圈（可選）
| 幀 | 內容 |
|----|------|
| 0 | 小亮圈 |
| 1 | 擴張金／硃 |
| 2 | 大圈淡墨邊 |

### clash.png — 兩刃相交／撞刃閃
| 幀 | 內容 |
|----|------|
| 0 | 兩短刃接近、尖端剛觸（墨／木亮邊） |
| 1 | **X 字交叉鎖刃**（金箔刃身 + cream 交點） |
| 2 | **爆亮**（cream／金箔核 + 硃紅尖放射硬點） |
| 3 | 刃影仍見、碎火花四散 |
| 4 | 刃淡、外散 mote |
| 5 | 殘點消散 |

播放建議：單次 one-shot，唔 loop；建議 **12–16 fps**。綁定時機：雙方 `attack` 交疊幀，或 `parry` 成功當下（可同幀觸發刀響／金屬碰）。中心對齊接觸點；可與 `spark`／`parry_flash` 錯 0–1 tick 疊用加強接觸感。

## 色盤
僅用 ART.md 墨點江湖盤（含角色擴充 teal／robe／violet）。生成腳本：`tools/gen_combat_fx.py`。
