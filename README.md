# 俠客棧（wuxia-inn）

墨點江湖風像素客棧經營＋出巡戰鬥。主畫面 **960×540** Hub；戰鬥同解析度疊層。

## 而家玩法摘要（v2.8.0）

1. **大廳 Hub**：點熱點——櫃檯經營升級、俠客席養成編隊、大門出巡、告示江湖劇情、地圖據點、書架藏書、廂房歇息／置物／夜半夢語。雅座可點菜／催單／小費；偶發短景（雨簷劍影／墨客題壁等）。
2. **經營**：接待客人賺銀／聲望；建設施（茶寮等）；解鎖青石／邊關分舵駐守。
3. **俠客**：招募、訓練、編隊（最多 3 人）、羈絆與雙人事件可帶短暫戰意。
4. **出巡**：自動走位戰鬥（靠近→蓄勢→出手）；已解鎖雙人羈絆同隊可 **合擊**（一場一次，成功有 toast）；出巡選敵可見「本隊可合擊：招名」；Boss 有短入場（可跳過）；速度預設 **1×**。
5. **劇情**：第一章至第六章開頭（餘燼之路／結局預告）；成就可喺江湖／日誌領獎；日誌有六組合擊／羈絆圖鑑，另有「而家可合擊」快捷摘要（已解鎖且可編／本隊就緒）。
6. **QoL**：新手三步引導、存檔 JSON 匯出匯入、離頁暫停、戰鬥教學可重開、直屏有橫屏提示。

音效暫緩；戰鬥減震維持輕量。

## 本地開啟

用瀏覽器直接開 `index.html`（或任意靜態伺服器）。存檔在 `localStorage`（`wuxia-inn-save-v1`）。
